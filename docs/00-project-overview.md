# LinkedIn AI Job Matcher

## Problem
Job seekers manually compare resumes with job descriptions.

## Solution
A Chrome extension that:
1. Reads user's resume
2. Reads LinkedIn jobs
3. Calculates relevance
4. Shows best matching jobs

## POC Goal
Show a relevance score for LinkedIn jobs based on resume skills.

## Out Of Scope
- User authentication
- Payment
- SaaS backend
- AI agents
- Cover letter generation
- Resume rewriting

## Success Criteria
User uploads resume.
User opens LinkedIn Jobs.
Extension shows:
- Match Score
- Matched Skills
- Missing Skills
