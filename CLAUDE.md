# Project Rules

Project: LinkedIn AI Job Matcher

Tech Stack
- React
- TypeScript
- Vite
- Tailwind
- Chrome Extension Manifest V3

Rules
1. Build only current phase.
2. Never implement future phases.
3. Keep code simple.
4. Avoid over-engineering.
5. No backend unless requested.
6. Use local storage first.
7. Each phase must compile successfully.
8. Generate complete code.
9. No pseudocode.
10. Explain file changes before coding.
